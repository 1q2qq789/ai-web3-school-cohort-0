## Handbook 阅读

- 章节：AI × Web3 Bridge → 链感知上下文（Chain-aware Context）
- 章节：AI × Web3 Bridge → Web3 工具调用（Web3 Tool Use）
- 章节：AI × Web3 Bridge → 智能体工作流（Agent Workflow）
- 章节：AI × Web3 Bridge → 智能体钱包（Agent Wallet）
- 章节：前沿探索 → 智能体商业（Agentic Commerce）

关键概念（Hackathon Openday 推荐阅读）：
- **Hackathon Openday 定位**：今天没有课程直播，是留给你的「方向沉淀日」。昨天听了「AI Agent × 区块链技术选择」和「VC 角度打磨项目」两场讲座，今天该做决定：你的 Hackathon 项目做什么？
- **Chain-aware Context**：Agent 不能只是"调个 API 发交易"——它需要知道当前在哪条链、Gas 多少、区块确认状态。不同链的 Agent 体验完全不同
- **Web3 Tool Use**：Agent 调用链上工具的模式——读合约状态、构造交易、模拟执行、签名提交。工具调用失败的处理比 Web2 API 复杂得多
- **Agent Wallet**：权限粒度（每天最多花多少）、时间窗口、人机协同签名——这是 Hackathon 项目的安全底线
- **Agentic Commerce**：机器支付、结算托管——如果你的 Hackathon 项目涉及支付流，这是必须理解的概念

## Handbook 阅读

> 今天是 Deadline Day，Handbook 阅读聚焦「如何从想法变成可提交的项目包」：

- 章节：AI × Web3 Bridge → **智能体工作流（Agent Workflow）** — Task decomposition + tool orchestration + state management
- 章节：AI × Web3 Bridge → **Web3 工具调用（Web3 Tool Use）** — Agent 与链上交互的读/写安全原则
- 章节：AI × Web3 Bridge → **智能体钱包（Agent Wallet）** — Pact 机制：预算、范围、时间窗口
- 章节：前沿探索 → **钱包与权限（Wallet / Permission）** — 权限分层、人工确认、撤销与审计

关键概念：

- **Agent Workflow**：Hackathon 提交中最重要的不是「用了什么模型」，而是「Agent 如何从用户输入走到链上执行结果」。画清楚这个流程 = 方向卡的核心。
- **Web3 Tool Use**：读操作可以自动，写操作必须有确认节点。这在项目设计中必须体现——评委不会给「自动签名转账」的 demo 高分。
- **Agent Wallet / Permission**：Cobo CAW 的 Pact 机制——不是为了展示技术，而是为了证明「这个 Agent 的权限是可控的」。

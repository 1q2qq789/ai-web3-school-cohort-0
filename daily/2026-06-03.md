## Handbook 阅读

> 今日 Co-learning 主题是"任务推进与答疑"——建议针对性阅读与你的 Hackathon 方向相关章节

- 章节：AI × Web3 Bridge → 链感知上下文（Chain-aware Context）
- 章节：AI × Web3 Bridge → Web3 工具调用（Web3 Tool Use）
- 章节：AI × Web3 Bridge → 智能体工作流（Agent Workflow）
- 章节：AI × Web3 Bridge → 智能体钱包（Agent Wallet）
- 章节：AI × Web3 Bridge → 机器支付（Machine Payment）

关键概念：
- **Co-learning 怎么用**：不是泛泛听课，是带着你昨天 Hackathon Openday 产出的问题去讨论——赛道选了吗？项目做什么？卡在哪？
- **Chain-aware Context**：你的 Agent 不能脱离链——读区块确认状态、Gas 价格、当前网络，这些决定你的项目能不能跑通
- **Web3 Tool Use**：读合约 → 构造交易 → 模拟执行 → 签名提交。失败处理比 Web2 API 复杂得多
- **Agent Wallet**：权限粒度（每天上限）、时间窗口、人机协同签名——Hackathon 项目的安全底线
- **Machine Payment**：机器间自动支付流——如果你的项目涉及支付闭环

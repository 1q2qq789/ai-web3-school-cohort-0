## Handbook 阅读

> Demo Day 后，适合从「实战」回到「理论」，用刚经历的项目反刍关键概念：

- 章节：AI × Web3 Bridge → **智能体工作流（Agent Workflow）** — 复盘你的项目：用户意图 → 任务拆解 → 工具调用 → 链上执行 → 结果验证，这条链路完整吗？
- 章节：AI × Web3 Bridge → **智能体钱包（Agent Wallet）** — Pact 三角（预算 + 时间窗口 + 权限撤销）在你的项目里实现了吗？
- 章节：AI × Web3 Bridge → **可验证 AI（Verifiable AI）** — 你的 Agent 做了什么可以链上验证？评委看这个
- 章节：前沿探索 → **智能体商业（Agentic Commerce）** — 你的项目属于哪类商业场景？下一步往哪走？
- 章节：前沿探索 → **AI 安全（AI Security）** — Demo 后回顾：你的 Agent 有什么安全漏洞？

关键概念：
- **复盘四问**：做了什么 / 学到了什么 / 最大的挑战 / 下一步去哪
- **从 Demo 到产品**：Demo 只需要跑通一次，产品需要考虑 edge case、安全、可维护性
- **学习闭环**：问题定义 → 共学训练 → 项目实践 → 对外展示 → 人才沉淀。你走到了哪一步？

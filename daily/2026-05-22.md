## Handbook 阅读

- 章节：https://aiweb3.school/zh/handbook/
- 今日重点（Week 1 收官 + Week 2 衔接）：
  - [Agent](https://aiweb3.school/zh/handbook/ai/agent/)：模型进入工具调用和多步执行
  - [Wallet](https://aiweb3.school/zh/handbook/web3/wallet/)：钱包不只是登录，而是身份和签名入口
  - [Agent Workflow](https://aiweb3.school/zh/handbook/bridge/agent-workflow/)：哪些步骤适合自动化，哪些必须 human-in-the-loop
  - [Agent Wallet](https://aiweb3.school/zh/handbook/bridge/agent-wallet/)：Agent 能拿什么权限，如何限制和撤销
- 关键概念：
  - Prompt → Workflow → Agent 的边界：prompt 是单次问答，workflow 是固定多步流程，agent 是自主决策+工具调用
  - 签名不是「点一下确认」，而是授权一个具体动作
  - AI Agent 不应直接接触私钥/助记词，涉及签名/转账/合约写入必须人工确认
  - Web3 Tool Use：RPC、钱包、合约工具如何被 Agent 调用

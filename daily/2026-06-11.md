## Handbook 阅读

> Demo Day 前夜，聚焦「演示链条」——评委看的就是你的 Agent 从输入到链上执行的完整路径：

- 章节：AI × Web3 Bridge → **智能体工作流（Agent Workflow）** — 用户输入 → 链上执行 → 结果验证，这条线不能断
- 章节：AI × Web3 Bridge → **Web3 工具调用（Web3 Tool Use）** — 读自动、写确认。Demo 里必须有一个写操作确认节点
- 章节：AI × Web3 Bridge → **智能体钱包（Agent Wallet）** — Pact 三角：预算范围 + 时间窗口 + 权限撤销。如果用了 Cobo 钱包，这是安全层核心卖点
- 章节：前沿探索 → **开发工具（Dev Tooling）** — 你用的工具够不够演示？今晚别换工具
- 章节：AI × Web3 Bridge → **链感知上下文（Chain-aware Context）** — Agent 怎么理解链上状态？Demo 里展示你的 Agent 知道"现在发生了什么"

关键概念：
- **Agent Workflow**：从用户意图 → 任务拆解 → 工具调用 → 链上执行 → 结果验证。评委看完整闭环
- **Web3 Tool Use**：每个写操作前有一个确认/模拟步骤，Demo 展示这个安全边界
- **Pact**：不是"允许 Agent 做所有事"，而是"在这个预算内、这段时间、这些操作"——安全的第一性原理
- **Demo Story**：不要讲技术，讲故事——"用户想做什么 → Agent 怎么帮了他 → 结果是什么"

## Handbook 阅读

- 章节：AI 基础 → Agent / MCP / Frameworks；AI × Web3 Bridge → Agent Workflow / Web3 Tool Use / Chain-aware Context
- 关键概念（Week 1 复习）：
  - **Chain-aware Context**：Agent 需要理解链上状态（余额、nonce、Gas、网络拥塞）才算真正进入 Web3 场景
  - **Web3 Tool Use**：工具调用在 Web3 中有额外的安全要求——签名权限、模拟交易、Gas 估算
  - **Agent Workflow**：多轮组织 + 状态管理 + 工具调用 + 日志记录 + 人工确认节点
  - **Agent Wallet**：AI 不应直接持有私钥；权限需要额度、时间和撤销条件约束
  - **Architecture**：今晚「AI 时代 Web3 开发者的基础知识和架构能力」是 Week 1 所有概念的系统整合
- 问题（待写入 handbook-feedback/）：Web3 开发者从 Web2 迁移过来，架构思维上最大的转变是什么？

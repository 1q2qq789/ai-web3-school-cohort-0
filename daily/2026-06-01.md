## Handbook 阅读

- 章节：AI 基础 → 智能体（Agent）
- 章节：AI 基础 → 框架（Frameworks）
- 章节：AI 基础 → 模型上下文协议（MCP）
- 章节：Web3 基础 → 网络（Network）
- 章节：Web3 基础 → 钱包（Wallet）
- 章节：Web3 基础 → 智能合约（Smart Contract）
- 章节：AI × Web3 Bridge → 智能体工作流（Agent Workflow）
- 章节：AI × Web3 Bridge → Web3 工具调用（Web3 Tool Use）
- 章节：AI × Web3 Bridge → 链感知上下文（Chain-aware Context）
- 章节：前沿探索 → 智能体商业（Agentic Commerce）

关键概念：
- **AI Agent 时代的技术选型**：当 AI Agent 能自主调用链上工具、管理钱包、执行交易——区块链的选择不再只是「TPS 和 Gas」，而是 Agent 的可编程性、可验证性和安全性
- **Agent 框架选择**：LangChain / Eliza / Rig / CrewAI 等框架各有侧重——Agent 自主性、多 Agent 协作、链上工具集成深度
- **MCP（模型上下文协议）**：Agent 与外部工具/数据源的标准接口，Web3 场景下 MCP Server 可以暴露链上数据、合约调用、钱包操作
- **钱包 × Agent**：Agent Wallet 不只是「让 AI 有个钱包地址」——涉及权限粒度、额度限制、时间窗口、人机协同签名
- **链感知上下文（Chain-aware Context）**：Agent 需要理解它在哪条链上、当前区块状态、Gas 价格、待处理交易——这些不是通用 LLM 的知识
- **从 VC 角度打磨项目**：黑客松项目不只是「功能跑通」，VC 看的是问题定义、市场规模、竞争壁垒、团队能力——建议带着这 4 个维度回看自己的项目方向

## Handbook 阅读

- 章节：AI × Web3 Bridge → 智能体钱包（Agent Wallet）、机器支付（Machine Payment）、智能体身份（Agent Identity）
- 章节：AI × Web3 Bridge → AI 安全（AI Security）、AI 隐私（AI Privacy）
- 章节：AI 基础 → 上下文（Context）、检索增强生成（RAG）
- 关键概念：
  - **Agent Wallet**：AI 不应直接持有私钥，权限需额度、时间和撤销条件约束
  - **Machine Payment**：AI Agent 自动完成小额支付（如 API 调用费、Gas 费）
  - **Agent Identity**：Agent 在链上的身份表示——合约地址、DID、ENS
  - **AI Privacy**：本周末 Neo-Cypherpunk 主题前置——TEE、ZK、FHE 等隐私技术如何保护 Agent 数据
  - **Context + Memory**：承接周三的 Long-term Memory 主题，Agent 记忆如何与链上状态结合

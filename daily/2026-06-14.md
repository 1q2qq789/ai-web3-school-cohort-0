## Handbook 阅读

> ⚠️ 数据来源：Handbook 主页 TOC（BYOB browser_read 成功加载）
> Demo Day 后第二个复盘日，适合从「项目实战」回到「长期路线」——你的项目下一步往哪走？

- 章节：前沿探索 → **智能体商业（Agentic Commerce）** — 你的 Hackathon 项目属于哪类商业场景？定价 / 结算 / 托管 / 订阅 / 按次付费？
- 章节：前沿探索 → **钱包与权限（Wallet / Permission）** — 项目中的 Agent 钱包权限模型够用吗？Pact（预算 + 时间窗口 + 撤销）实现了吗？
- 章节：前沿探索 → **AI 安全（AI Security）** — 评委有没有问到安全问题？prompt injection / 权限越权 / 金额异常？
- 章节：前沿探索 → **治理（Governance）** — 如果你的项目要有社区治理，DAO 投票 or Agent 自动决策？

关键概念：
- **从 Demo 到产品**：Demo 验证「能做」，产品需要「稳做」——错误处理、边界 case、用户引导、可维护性
- **四周能力地图**：AI 基础 → Web3 基础 → AI × Web3 Bridge → 前沿探索。你走完了，画一下自己最强的区域和最需要补的区域
- **下一步三问**：继续深入 AI × Web3？报名下一期？还是把项目带到真实黑客松？

## Handbook 阅读

> 最后一周的 Handbook 聚焦「从 Demo 到产品」——四个前沿方向覆盖 Agent 产品化全链路。

- **智能体商业（Agentic Commerce）**：你的 Agent 怎么变现？订阅 / 按次 / 托管 / 免费增值？支付通道怎么选？
- **钱包与权限（Wallet / Permission）**：Pact 三角（预算 + 时间窗口 + 权限撤销）是 Agent 产品化的安全基线
- **AI 安全（AI Security）**：prompt injection / 金额越权 / 权限泄露——产品上线前的安全自查清单
- **开放赛道（Open Track）**：下一步往哪走？下一期课程 / 独立项目 / 加入团队 / 参加黑客松？

关键概念：
- **从 Demo 到产品**：Demo 跑一次就够，产品要处理错误、边界、用户引导、安全、可维护性
- **四周闭环完成**：问题定义 → 共学训练 → 项目实践 → 对外展示 → 人才沉淀 🎯
- **你的能力地图**：四周结束后，画一张自我评估图——最强 3 区 + 最弱 3 区

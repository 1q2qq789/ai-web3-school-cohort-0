## Handbook 阅读

> 今日核心讲座：AI Agent 时代重新审视区块链 — 这是 Week 3 最重要的一讲，把 AI 和 Web3 的本质交叉讲清楚

- 章节：AI × Web3 Bridge → **AI 安全（AI Security）**
- 章节：AI × Web3 Bridge → **智能体工作流（Agent Workflow）**
- 章节：AI × Web3 Bridge → **链感知上下文（Chain-aware Context）**
- 章节：AI × Web3 Bridge → **可验证 AI（Verifiable AI）**
- 章节：AI × Web3 Bridge → **智能体身份（Agent Identity）**
- 章节：前沿探索 → **AI 安全（AI Security）**
- 章节：前沿探索 → **钱包与权限（Wallet / Permission）**

关键概念：

- **AI Agent × 区块链**：AI Agent 不是"调用一个 API"这么简单。“AI Agent 时代重新审视区块链”这一讲的核心命题是：当 Agent 从回答问题进入自主执行，传统中心化架构（单点故障、权限集中、不可审计）的短板暴露——区块链的不可篡改、去中心化执行、可验证记录恰好补上这些缺口。
- **Chain-aware Context**：Agent 的工作上下文不再只是对话历史，还要包括链上状态（余额、nonce、合约数据、Gas 价格）。上下文污染 = 错误执行。
- **AI Security**：Agent 接入链上 = 安全边界急剧扩大。Prompt injection → 恶意交易；Tool abuse → 资金盗取；密钥托管 → 单点风险。原则：Agent 不应直接持有私钥；涉及签名/转账必须保留人工确认节点。
- **Verifiable AI**：链上执行天然可验证——交易哈希、合约地址、事件日志都是 Audit Trail。AI 的输出可以上链存证，形成可追溯的责任链。
- **Agent Identity**：链上 Agent 不是"一个对话 session"，而是有地址、有权限、有历史记录的执行实体。

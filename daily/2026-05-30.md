## Handbook 阅读

- 章节：AI 基础 → 上下文（Context）
- 章节：AI 基础 → 检索增强生成（RAG）
- 章节：AI × Web3 Bridge → 可验证 AI（Verifiable AI）
- 关键概念：
  - **Context**：LLM 的上下文窗口是短期记忆上限；token 预算决定 agent 能同时"记住"多少信息
  - **RAG（检索增强生成）**：通过外部知识库检索补充 LLM 的固定知识，解决"模型训练截止后"的信息盲区
  - **Long-term Memory**：超越单次会话的记忆——持久化用户偏好、任务历史、决策记录，让 agent 在多轮/多天交互中保持一致性
  - **Verifiable AI**：链上记录 AI 的输出、决策和执行，提供可验证的证据链——与 long-term memory 天然互补
- 问题（待写入 handbook-feedback/）：

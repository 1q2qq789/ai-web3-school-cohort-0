## Handbook 阅读

> Week 4 是 Hackathon 冲刺周，阅读聚焦「从代码到 Demo」的执行链：

- 章节：AI × Web3 Bridge → **智能体工作流（Agent Workflow）** — 任务分解 + 工具编排 + 状态管理。先画清楚你项目的 Agent 从用户输入到链上执行的完整流程
- 章节：AI × Web3 Bridge → **Web3 工具调用（Web3 Tool Use）** — Agent 调用链上工具的读/写安全原则。Demo 中必须体现「读自动、写确认」的设计
- 章节：AI × Web3 Bridge → **智能体钱包（Agent Wallet）** — Pact 机制：预算、范围、时间窗口。Cobo CAW 的核心概念
- 章节：前沿探索 → **开发工具（Dev Tooling）** — Hackathon 可用的框架和工具链
- 章节：前沿探索 → **钱包与权限（Wallet / Permission）** — 权限分层、人工确认、撤销与审计

关键概念：

- **Agent Workflow**：Hackathon Demo 最核心的不是「用了什么模型」，而是「Agent 如何从用户输入走到链上执行结果」。周四 Demo Day 评委看的就是这个链条
- **Web3 Tool Use**：读操作自动，写操作必须有人工确认节点。Demo 中必须能演示这个安全边界
- **Agent Wallet / Pact**：预算范围 + 时间窗口 + 权限撤销 = Agent 安全执行的三角。如果你的项目用 Cobo，这就是核心卖点
- **Dev Tooling**：3 天开发时间，优先选你熟悉的工具。不要为了「用新技术」而浪费时间

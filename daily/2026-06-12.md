## Handbook 阅读

> Demo Day 聚焦「展示 + 复盘」——评委看你的 Agent 从输入到链上执行的完整路径，以及你的展示叙事：

- 章节：AI × Web3 Bridge → **智能体工作流（Agent Workflow）** — 用户输入 → 链上执行 → 结果验证。Demo 里展示完整闭环
- 章节：AI × Web3 Bridge → **Web3 工具调用（Web3 Tool Use）** — 读自动、写确认。评委关注安全边界
- 章节：AI × Web3 Bridge → **智能体钱包（Agent Wallet）** — Pact 三角：预算 + 时间窗口 + 权限撤销
- 章节：前沿探索 → **智能体商业（Agentic Commerce）** — 你的项目属于哪一类商业场景？Demo 里点出来
- 章节：前沿探索 → **开发工具（Dev Tooling）** — 复盘用什么工具、踩了什么坑

关键概念：
- **Demo 叙事公式**：用户想做什么 → Agent 怎么帮了他 → 链上发生了什么 → 结果是什么。不讲技术，讲故事
- **Agent Workflow 闭环**：意图 → 拆解 → 工具调用 → 链上执行 → 结果验证。评委看完整度
- **Pact 的安全边界**：预算 + 时间窗口 + 权限撤销，三位一体。Demo 里展示 Agent 的安全约束
- **复盘三问**：做了什么 / 学到了什么 / 下一步是什么

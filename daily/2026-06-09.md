## Handbook 阅读

> Week 4 冲刺，阅读聚焦「执行链」——明天 Z.AI 分享会前补一下 Agent 找机会相关的概念：

- 章节：AI × Web3 Bridge → **智能体工作流（Agent Workflow）** — 复习你的 Agent 从输入到链上执行的完整流程。Demo Day 评委看的就是这个
- 章节：AI × Web3 Bridge → **Web3 工具调用（Web3 Tool Use）** — 读自动、写确认。Demo 中必须能演示安全边界
- 章节：AI × Web3 Bridge → **智能体钱包（Agent Wallet）** — Pact 机制：预算、范围、时间窗口
- 章节：前沿探索 → **智能体商业（Agentic Commerce）** — 明天的 Z.AI 分享会主题「让 Agent 帮你找机会」，提前了解 Agent 怎么在商业场景里工作
- 章节：前沿探索 → **开发工具（Dev Tooling）** — 你现在用的工具够不够？Demo 前别换新工具

关键概念：

- **Agent Workflow**：明天 Demo Day 评委看的是你的 Agent 从用户输入到链上执行结果的完整链条。今天再跑一遍，确保没有断点
- **Agentic Commerce**：Agent 不只是执行器，还能主动发现机会——Z.AI 分享会的核心看点
- **Pact（Agent Wallet）**：预算范围 + 时间窗口 + 权限撤销。如果你的项目用了 Cobo，这就是安全层的核心卖点
- **Web3 Tool Use**：读自动、写确认。Demo 中找一个写操作的确认点展示给评委看

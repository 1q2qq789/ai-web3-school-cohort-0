## Handbook 阅读

- 章节：AI × Web3 Bridge → 链感知上下文（Chain-aware Context）、Web3 工具调用（Web3 Tool Use）、智能体工作流（Agent Workflow）
- 关键概念：

### 链感知上下文（Chain-aware Context）
> **模型不能凭语言记忆判断链上事实，链上事实必须从工具和索引层读取。**
- 链上状态有时间性：同一地址的余额、授权随区块变化
- 上下文必须带来源：chain id、block number、contract address、explorer link
- 区分事实和解释：工具返回事实，模型负责解释

### Web3 工具调用（Web3 Tool Use）
> **模型可以选择工具，但工具必须用确定性边界限制模型。**
- 读写分离：读链和写链必须是不同工具、不同权限
- 参数结构化：chain id、contract、method、value 不能埋在自然语言里
- 日志不可省：每次工具调用记录输入、输出、时间、来源和错误
- 写交易前必须：simulation + policy check + 用户确认

### 智能体工作流（Agent Workflow）
> **高风险 Agent 不能只有"下一步推理"，必须有状态、边界和停止条件。**
- Task Graph：把目标拆成节点和依赖（上下文→查询→计划→模拟→确认→执行→记录）
- State Machine：draft → plan_ready → waiting_user → submitted → confirmed
- Human-in-the-loop：小风险自动，高风险必须人工确认
- Trace + Regression Set：可回放、可评估

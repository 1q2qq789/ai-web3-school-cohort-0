## Handbook 阅读

> 今天是 Hackathon 冲刺前的最后准备日。推荐阅读 AI × Web3 Bridge 中与「把想法变成可执行项目」最相关的章节：

- 章节：AI × Web3 Bridge → **智能体工作流（Agent Workflow）** — 如何把 Agent 从对话变成执行流程
- 章节：AI × Web3 Bridge → **Web3 工具调用（Web3 Tool Use）** — Agent 如何与链上交互
- 章节：AI × Web3 Bridge → **链感知上下文（Chain-aware Context）** — Agent 的上下文不止对话，还有链上状态
- 章节：AI × Web3 Bridge → **智能体身份（Agent Identity）** — 链上 Agent 的身份、权限和历史
- 章节：前沿探索 → **钱包与权限（Wallet / Permission）** — Hackathon 项目的权限设计

关键概念：

- **Agent Workflow**：从"回答问题"到"执行任务"的关键跃迁。Workflow = 任务分解 + 工具编排 + 状态管理 + 结果验证。在 Hackathon 项目中，先画出你的 Agent 从接收用户输入到输出结果的完整流程。
- **Web3 Tool Use**：Agent 调用链上工具不是简单的 API call——需要考虑交易模拟、Gas 估算、签名确认、失败回滚。原则：读操作可以自动，写操作需要确认节点。
- **Chain-aware Context**：Agent 的工作上下文不仅包括对话历史，还包括链上实时状态（余额、nonce、合约数据）。忽略链上上下文 = 错误执行。
- **Wallet / Permission**：你的 Hackathon 项目中 Agent 的权限边界在哪里？能自动调用什么？什么需要用户确认？
